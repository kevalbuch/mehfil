# Mehfil — Platform Improvements & Execution Roadmap

This living roadmap documents all planned UI, UX, functional, mobile, and ecosystem improvements for **Mehfil (India Sound Culture Engine)**. As each item is completed, this checklist is updated.

---

## 📋 Master Execution Checklist

### Phase A: Audio Experience & Creator Quick-Wins (High Priority)
- [x] **A1. Persistent Sticky Bottom Mini-Player**: A floating bottom player bar that slides up when any track plays, featuring rotating mini-vinyl art, song title, artist, live waveform visualizer, play/pause, 15s countdown timer, and volume mute/unmute.
- [x] **A2. Direct Instagram Audio Deep-Links**: Add dual outbound action (`[Instagram Audio ↗]` alongside `[Spotify ↗]`) across sound cards, modals, and drops so creators can jump straight to Instagram Reels audio.
- [x] **A3. Inline ▶ Cue in Search (⌘K)**: Instant audio preview auditioning button directly within search result rows without having to open the modal first.
- [x] **A4. Hybrid Live Search in ⌘K**: Expand search beyond static catalog to query live dynamic music corridors when query has < 3 results.

### Phase B: Aesthetic Experience & Audio Tools (Medium-High Priority)
- [x] **B1. "Midnight Studio" Dark Theme Switcher**: 1-click theme switch (`☀️ Paper Editorial` ⇄ `🌙 Midnight Studio`) with deep obsidian backgrounds (`#121114`), luminous vinyl grooves, and warm gold foil accents.
- [x] **B2. Sound Twin A/B Audio Switcher**: Interactive `[Audition Original]` vs `[Audition Underground Twin]` toggle inside the Sound Story modal for instant side-by-side comparison.
- [x] **B3. Interactive Waveform Audio Scrubber**: Clickable/draggable progress seek on the waveform canvas to jump to specific moments in the 30-second audio stream.

### Phase C: Vault Management & Studio Exporters (Medium Priority)
- [x] **C1. Advanced Vault Board Management**: Full board controls inside The Vault drawer: Rename custom board, Duplicate board, Clear all sounds, Delete custom board (with safeguards), and live board statistics.
- [x] **C2. Studio Multi-Ratio High-Res Card Exporter**: High-resolution canvas renderer allowing creators to export their board into `16:9 Desktop / Presentation`, `1:1 Square Album Artwork`, or `9:16 Story` with custom typography and color schemes.
- [x] **C3. Batch Creator Blueprint Exporter**: 1-click batch copy of the entire board's reel hook timestamps, caption angles, and hashtag bundles for desktop video editors (Premiere, Final Cut, CapCut).

### Phase D: Editorial Intelligence & Video Pacing (Strategic)
- [x] **D1. Video Editing BPM & Pacing Sorter**: Filter sounds by video edit pacing (*Slow-Mo <90 BPM*, *Walking / Lifestyle 95-115 BPM*, *Fast-Cut / Bass Drop >125 BPM*) with live BPM tags on cards.
- [x] **D2. Scene Radar Intelligence Report Exporter**: Export emerging regional scene velocity, artist analytics, and trajectory telemetry as clean CSV / JSON / Markdown summary.
